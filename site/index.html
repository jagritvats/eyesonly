Git, but not all-or-nothing.

Eyes Only adds private files, private branches and built-in secrets to any git repo. Your .env lives next to the code, encrypted for the people who should read it. The server enforces the rules, so nobody can push around them, and everyone keeps using plain git.

Three layers, stock git

A commit hashes its whole tree, so git can't leave a file out for one person. Eyes Only keeps the tree identical for everyone and controls who can read the blobs, who can see each ref, and what the server will accept.

01 · client

Encrypted files

A clean/smudge filter seals protected paths with AES-256-GCM, wraps the key per reader with X25519 and signs it with Ed25519. Unchanged files don't churn, and git diff shows plaintext to readers.

02 · proxy

Invisible branches

An authenticating smart-HTTP proxy hides private/* from everyone outside the audience. It forces protocol v0 so hidden commits can't be fetched by SHA, and serves no dumb HTTP.

03 · hook

Server-side enforcement

A pre-receive hook checks every commit against the server's policy: no plaintext secrets, no unauthorized edits, no forged or replayed ciphertext, and no private history merged into main.

What Eyes Only doesn't do

Security tools lose trust by over-claiming, so here are the limits. Details are in THREAT_MODEL.md.

Revocation isn't retroactiveSomeone who could read a secret has seen it. eyesonly audit <user> lists exactly what to rotate.
File names and timestamps are visibleOutsiders see that .env exists and when it changed, but not what's in it.
The server sees private branchesIt never sees file plaintext, but private refs are ordinary objects on the server.
Run it behind TLSTokens are bearer credentials. Put Caddy or nginx in front.

Quickstart

Five minutes on your own box. Production setups put the server behind TLS.

# server eyesonly-server user add eyesonlypub1:eyJuYW1lIjoiYWxpY2Ui… # prints alice's token eyesonly-server repo create app.git --admin alice eyesonly-server policy set app.git policy.json eyesonly-server serve --port 8787 # policy.json { "members": ["*"], "groups": { "core": ["alice", "bob"] }, "files": { ".env": ["@core"], "secrets/**": ["@core"] }, "branches": { "refs/heads/private/": ["@core"] } } # each developer eyesonly keygen alice eyesonly clone https://alice:<token>@git.example.com/app.git # ...then it's just git
